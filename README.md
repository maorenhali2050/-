# 图书馆管理系统（大专毕业设计）

第一版项目骨架。目标是先完成图书查询、借阅和归还，再增加三个创新模块。
当前仅有静态开发入口和设计说明；没有登录、数据库、真实借还或自动任务。

## 本地查看
安装 Python 3，在仓库根目录执行：
```bash
python -m http.server 8000 --directory frontend
```
浏览器打开 http://localhost:8000 。页面用于导航和说明，不会修改借阅数据。

## 目录
| 路径 | 用途 |
| --- | --- |
| frontend/ | 静态前端入口；后续可迁移至学校要求的框架 |
| backend/ | API、业务服务和定时任务开发入口 |
| database/ | 表结构与样例数据规划 |
| docs/modules.md | 三个创新模块的边界、规则与验收条件 |
| docs/development-plan.md | 开发顺序与每阶段交付物 |
| docs/api-contract.md | 待实现的接口约定 |
| tests/ | 后续业务测试与验收入口 |

## 三个模块
| 模块 | 页面入口 | 职责 |
| --- | --- | --- |
| 个性化图书推荐 | 首页“为你推荐” | 根据借阅类别统计推荐图书，无历史时推荐热门图书 |
| 借阅逾期智能提醒 | 我的借阅、管理员逾期列表 | 判断逾期并生成站内提醒 |
| 图书自动流转 | 图书详情预约、管理员预约列表 | 归还后为有效预约队首保留可借副本 |

“自动流转”暂指预约分配，不代表实物运输、跨馆调拨或自动确认读者已借出。
第一版采用规则实现，不需要训练机器学习模型或接入短信服务。
